# LordPercivalXII's Balatro Deck Skin Mod - 3DS Edition

This is just a small mod that adds a custom deck face theme, based on characters that I've designed over the years.

Now converted for use on Balatro 3DS!

## Art Style

Due to the modding limitations of Balatro 3DS, only the base edition (collab) of the designs are used. Additionally, only the 1x scale assets are used, with all pngs converted to t3x for use on the 3DS version.

Do note that whatever is shown below may differ to what appears in game, mainly due to scaling, colours (e.g. Navy Blue colour may show as Dark Blue/Almost Black) and the png to t3x conversion.
